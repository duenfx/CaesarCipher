У цьому проєкті реалізовано:
1)шифрування(клас Encrypt з методом encryptText()) та дешифрування(клас Decrypt з методом decryptText()) файлів шифром Цезаря з циклічним зсувом по алфавіту.
2)режим "Brute_force" - підбір ключа та розшифровування тексту. Щоб виявити чи правильно підібрано ключ я додала метод isReadable(), який перетворює текст у нижній регістр та 
має масив ключових базових слів. Якщо хоча б 3 таких слова знайдено у розшифрованому тексті, то він вважається правильно розшифрованим.
3)клас CLI для запуску з консолі.
4)операції з файлами: при певній обробці створюється новий файл з відповідним суфіксом.
Особливості:
1)алфавіт було реалізовано в класі Encrypt, як константу, а також було додано гетер для доступу нього з інших класів.
2)символи, які є поза алфавітом залишаються незмінними.
